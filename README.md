# 📺 Netflix Data Analysis

A Python data analysis project focused on exploring, cleaning, analyzing, and visualizing the **Netflix Movies & TV Shows** dataset using **Pandas** and **Matplotlib**.

---

## 📚 Learning Objectives

- Practice data exploration with Pandas
- Learn to clean real-world datasets
- Perform exploratory data analysis (EDA)
- Create meaningful visualizations
- Build confidence working with larger datasets

---

- [ ] Which columns contain missing values?

### Concepts

- Reading CSV files
